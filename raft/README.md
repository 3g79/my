# 桴

私人说明书，不是救国连载。

过去四十年是例外。公共解法对不上。私人只剩两条：不当父母，或让孩子离开这套户籍和叙事。

## 怎么读

先读 `00-总图.md`。其余各篇只砍一刀，读完应能回答：这一刀砍在哪、和两条私路怎么接。不必按序读完。叶子由分头撰写后收回同一目录，口径以总图为准。

- 父母从 `09` 进。
- 青年从 `10` 进。
- 宏观从 `00`、`08` 进。
- 单点从 `01`–`07` 进。

## 写法

- 一篇一个机制。新材料并进已有叶子，不新开“有感”。
- 禁止为公平而加对冲段。不写“另一面也有道理”。
- 不写唤醒人民、不写一起改变、不写具体偷渡或违法出境步骤。
- 数字用讨论里核过的口径；不确定就写“大约／公开数是乐观上限”。
- 每篇收在两条私路上，指向 `00`。
