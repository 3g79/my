# 这个仓库是什么

私人主题文库。第一主题是「桴」：过去四十年是例外；公共解法对不上；私人只剩停生，或让孩子离开这套户籍和叙事。

不是救国机关，不是内容工厂。一篇进来，应能独自读完，并知道出处在哪。

## 怎么读

1. [topics/桴/00-总图.md](topics/桴/00-总图.md)
2. 其余按需。父母从 `09`，青年从 `10`。
3. 数字以 [topics/桴/sources.md](topics/桴/sources.md) 为准。

## 怎么长

主题是树，不是仓库。新材料并进已有叶子。新主题另开 `topics/名/`，自带总图和出处账本。治理只保留根目录 `AGENTS.md` 这一页。
